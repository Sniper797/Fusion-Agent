# FusionAgent — شغّل Fusion بسكربتات Python من خارجه

إضافةٌ صغيرة لـ Autodesk Fusion تجعل أيّ برنامجٍ خارجه يقرأ التصميم المفتوح ويقيسه ويعدّله، بلا شاشةٍ ولا نقرات. البرنامج قد يكون سطر الأوامر، أو Claude Code، أو أيّ وكيل ذكاءٍ اصطناعيّ.

**كيف تعمل:**
1. تكتب سكربت Python، وتشغّله بالأمر `run_job.py`.
2. يضع الأمر «مهمّة» في مجلّد، فتلتقطها الإضافة داخل Fusion خلال نصف ثانية.
3. تنفّذ الإضافة السكربت، وتعيد النتيجة بصيغة JSON.

النسخة الإنجليزيّة: [README.en.md](README.en.md)

## ماذا يمكن أن تفعل بها

- **قراءة التصميم وقياسه.** المكوّنات والأجسام وأحجامها وأبعادها، والمفاصل وسلامتها، في ثوانٍ حتى لتجميعٍ من 270 جسماً.
- **الفحص قبل الطباعة.** هل يتداخل جزءان؟ وما أصغر خلوصٍ بينهما؟
- **تعديل التصميم بدقّة، ثمّ إثبات التعديل بالأرقام.** مثاله تحويل شافتٍ إلى قفل سناب يركب عليه ترسٌ ويبقى يدور (`snap_fit.py`).
- **التصدير دفعةً واحدة.** ملفّ STL لكلّ جسم، ونسخةٌ احتياطيّة f3d.
- **صورٌ للنموذج** للتقارير والمنشورات.
- **توليد قطعٍ من بيانات.** مثلاً ميداليةٌ باسم كلّ طالب من قائمة. هذا ليس من الأمثلة، تكتب سكربته بنفسك.
- **أيّ شيءٍ تتيحه Fusion API.** السكربت Python كامل يعمل داخل Fusion.

## التثبيت (مرّة واحدة)

تحتاج Autodesk Fusion، وPython 3.7 أو أحدث لتشغيل `run_job.py`. لا يحتاج `run_job.py` أيّ مكتبةٍ إضافيّة.

**نزّل الحزمة:** من GitHub، أو من ملفّ zip وصلك.

```
git clone https://github.com/Sniper797/fusion-agent.git
cd fusion-agent
```

**على Windows:**
1. شغّل `install-windows.bat`.
2. في Fusion افتح **Utilities ← Add-Ins** (أو Shift+S)، وابحث في القائمة عن **FusionAgent**، وشغّله بزرّ التشغيل أو بالمفتاح الذي بجانبه. شكل هذه النافذة يختلف قليلاً بين إصدارات Fusion. بعدها تعمل وحدها مع كلّ تشغيلٍ لـ Fusion.
3. تأكّد أنّها تعمل: `python run_job.py ping` يطبع اسم المستند المفتوح.

> **`run_job.py` لا يدخل Fusion.** لا تضفه إلى قائمة Scripts and Add-Ins، فتشغيله من هناك لا يفعل شيئاً. هو المُرسِل الذي يعمل من الطرفيّة (cmd أو PowerShell أو Terminal)، أو يشغّله Claude Code. الذي يدخل Fusion هو الإضافة `FusionAgent` وحدها.

**على macOS:** انسخ مجلّد `FusionAgent` إلى
`~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/`
ثمّ نفّذ الخطوتين 2 و3.

**التحديث:** نفّذ `git pull`، ثمّ شغّل `install-windows.bat` من جديد، ثمّ أعد تشغيل Fusion. فالإضافة نسخةٌ في مجلّد Fusion، ولا تتحدّث وحدها حين يتحدّث المستودع.

## الاستعمال

```
python run_job.py ping
python run_job.py examples/inspect_design.py
python run_job.py examples/check_clearance.py --args "{\"only\": [\"Gear\"]}"
python run_job.py examples/export_stl.py --args-file my_args.json --save result.json
```

**ماذا يطبع:** ما طبعه السكربت، ثمّ `out`. وإن فشل السكربت يطبع الخطأ كاملاً.

**رمز الخروج:**

| الرمز | معناه |
|---|---|
| 0 | نجح |
| 1 | خطأٌ في السكربت |
| 2 | الإضافة لا تعمل، أو مدخلٌ خاطئ |
| 3 | الإضافة مشغولة بمهمّةٍ أخرى |
| 4 | انتهت المهلة |

python run_job.py examples/demo_scene.py

## اكتب سكربتك

السكربت ملفّ Python عاديّ يعمل داخل Fusion، ويجد هذه الأسماء جاهزة:

| الاسم | ما هو |
|---|---|
| `app`، `ui`، `adsk` | تطبيق Fusion وواجهته ومكتبة الـ API |
| `args` | ما أرسلتَه بـ `--args` أو `--args-file` |
| `out` | قاموسٌ يعود إليك نتيجةً |
| `flush()` | يكتب النتيجة الآن. استدعه بعد كلّ خطوةٍ في المهامّ الطويلة |
| `agent_dir` | مجلّد الإضافة، والمكان الافتراضيّ للمخرجات |
| `design()` | التصميم المفتوح |
| `find_occurrence(name)` | مكوّنٌ باسمه |
| `bbox_mm(e)`، `mm()`، `cm()`، `point_mm(x, y, z)` | الأبعاد وتحويل الوحدات |
| `try_value(fn, default)` | القيمة، أو البديل إن رفض Fusion حسابها |
| `to_component_space`، `add_tool_and_combine`، `require_timeline_at_end`، `group_timeline` | أدوات التعديل الآمن، وطريقة استعمالها في `snap_fit.py` |
| `save_viewport(path, w, h, fit)`، `safe_name(text)` | صورة العرض، واسم ملفٍّ سليم |

- ما يطبعه `print` يعود إليك أيضاً.
- الوحدات القياسيّة مثل `os` و`math` استوردها بنفسك.
- **وحدة الطول الداخليّة في Fusion هي السنتيمتر**، فحوّل بـ `mm()` و`cm()`.

```python
# hello.py
d = design()
out["document"] = app.activeDocument.name
out["occurrences"] = d.rootComponent.allOccurrences.count
print("ok")
```

ثمّ: `python run_job.py hello.py`

## قواعد تحمي تصميمك

1. **خذ نسخةً احتياطيّة قبل أيّ تعديل:** `backup_f3d.py`.
2. **اقرأ قبل أن تعدّل.** قِس المقاسات من الملفّ نفسه، ولا تعتمد على الذاكرة.
3. **أضف في آخر الخطّ الزمنيّ، واجمع الإضافات في مجموعة.** تحذفها بضغطةٍ إن لم تعجبك.
4. **أثبت التعديل بالأرقام:** شغّل `check_clearance.py` بعده.
5. **الإضافة لا تحفظ مستنداتك.** الحفظ بيدك.

## الأمان: اقرأ هذا

تشغّل الإضافة **أيّ** ملفّ Python تشير إليه المهمّة، بصلاحيّات حسابك على الجهاز. فمن استطاع الكتابة في مجلّدها استطاع تشغيل كودٍ على جهازك.

- **أين المجلّد:** `%LOCALAPPDATA%\FusionAgent` على Windows، و`~/Library/Application Support/FusionAgent` على macOS، وكلاهما داخل حسابك.
- **لا تنقله إلى مجلّدٍ مشترك أو متزامن** مثل OneDrive أو Dropbox. يمكن تغييره بالمتغيّر `FUSION_AGENT_DIR`، فانتبه أين تضعه.
- **لا تشغّل سكربتاً لم تقرأه.**
- **لإيقافها:** Shift+S، ثمّ FusionAgent، ثمّ **Stop**، وأزل علامة **Run on Startup**.

## مشكلاتٌ معروفة

- **«FusionAgent is not running»:** Fusion مغلق، أو الإضافة متوقّفة. شغّلها من Shift+S.
- **«busy»:** مهمّةٌ أخرى تعمل الآن، وقد تكون من جلسةٍ أخرى تستعمل الإضافة نفسها، فالمهامّ تُنفَّذ واحدةً واحدة. وإن طال الانتظار فغالباً نافذةٌ مفتوحة في Fusion، مثل Scripts and Add-Ins، تحبس المهامّ حتى تُغلق. وإن انهار Fusion أثناء مهمّة، فالإضافة تنظّف بقاياها عند تشغيله التالي.
- **انتهت المهلة:** في الغالب نافذة حوارٍ مفتوحة في Fusion تمنعه، فأغلقها. وللمهامّ الطويلة استعمل `--timeout 600`.
- **المسارات داخل `args`:** اكتبها بصيغة `C:/...`. مسار Git Bash مثل `/c/Users/...` يفشل بصمت.
- **تجمّد واجهة Fusion:** السكربت يعمل على خيط Fusion الرئيسيّ، فتتوقّف الواجهة حتى ينتهي. قسّم الأعمال الطويلة.
- **لا تبحث في ملفّات السحابة داخل مهمّة.** سكربتٌ مرّ على مشاريع `app.data` ومجلّداتها جمّد Fusion («Not Responding») مرّتين، مرّةً تسع دقائق ومرّةً قرابة أربعين، حتى أُعيد تشغيله. إن احتجت ملفّاً غير مفتوح فافتحه بيدك في Fusion أوّلاً. وإن عرفت مساره فادخل إليه بالاسم مباشرةً بـ `dataFolders.itemByName`، مستوىً بعد مستوى.
- **السكربت يعمل على المستند النشط.** `design()` وأدوات التعديل تأخذ المستند المفتوح أمامك الآن، أيّاً كان. فقبل أيّ سكربتٍ يعدّل، شغّل `ping` وتأكّد من اسم المستند.
- **جسمٌ لا يُحسب حجمه:** بعض الأجسام يرفض Fusion حساب حجمها أو المسافة إليها، مثل الأسطح المفتوحة والهندسة التالفة. الأمثلة تتخطّاها وتذكرها، واستعمل `try_value` في سكربتاتك.
